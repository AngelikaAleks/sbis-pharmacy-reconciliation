# Сверка выгрузки из аптеки и СБИС

Учебный проект системного аналитика.

## Контекст
Компания управляет сетью из 100 аптек и переходит с УСН на ОСН.
Нужно сверить данные о реализации товара из аптек с данными из СБИС
и сформировать единый файл для загрузки в 1С.

## Что внутри
- ТЗ (требования к скрипту)
- BPMN-схема процесса
- Пример итогового файла

## Стек
Python (pandas), BPMN, UML
